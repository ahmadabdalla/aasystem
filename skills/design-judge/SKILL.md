# Design Judge

Before starting, read the [shared execution contract](../pilot/references/execution.md) in full and the [approved-principle index](../principles/INDEX.md). Follow the contract's baseline requirements.

Own the [visual standards](references/visual-standards.md) and audits against them. Do not edit files, start remediation or redesign interactions. Interaction Design owns navigation, interaction models and rendered UX assessment.

## Select the assignment

A request to audit, review or check the visual consistency of tokens, components or UI code is an audit: follow [Design-system audit](references/design-system-audit.md) for the requested dimensions only.

## Return

Return the audit report. When the user or caller authorizes remediation, hand it to the [Feature playbook](../pilot/playbooks/feature.md). Return interaction-behaviour or business-meaning changes through the caller to [Interaction Design](../interaction-design/SKILL.md) or [Product](../product/SKILL.md).
