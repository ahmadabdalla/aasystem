# Investigation

Answer the question with checked citations. **Don't change the product** unless the user also asked for the change.

1. **Trace it.** Call the Skill tool twice, with "how" ([how](../../how/SKILL.md)) for how it works and with "why" ([why](../../why/SKILL.md)) for why it's that way or when it changed.
2. **Settle what reading can't.** If the question is which approach to take, call the Skill tool with "solution" ([solution](../../solution/SKILL.md)). If a runtime fact would change the answer, call the Skill tool with "probe" ([probe](../../probe/SKILL.md)) without touching the product.
3. **Check it.** Open every file and commit you cite and check it says what you claim. If sources disagree, say which wins and why. If you can't tell, report both.
4. **Answer.** Give the answer, alternatives if any, what you read, what you ran and what's still unknown. If the user wants it visual, call the Skill tool with "explain-visually" ([explain-visually](../../explain-visually/SKILL.md)). If the change was also asked for, hand the answer to the matching change playbook. Otherwise stop.
