# Investigation

Answer the question with sources you've checked. Don't change anything unless the user asked for the change too.

1. **Trace it.** If it's about code, call the Skill tool twice, with "how" ([how](../../how/SKILL.md)) for how it works and with "why" ([why](../../why/SKILL.md)) for why it's that way.
2. **Settle what reading can't.** If the question is which approach to take, call the Skill tool with "solution" ([solution](../../solution/SKILL.md)). If a runtime fact would change the answer, call the Skill tool with "probe" ([probe](../../probe/SKILL.md)).
3. **Check every source.** Open each file, commit or page you cite. If sources disagree, say which wins and why, or report both.
4. **Answer.** Give the answer, what you checked and what's still unknown. If the user wants it visual, call the Skill tool with "explain-visually" ([explain-visually](../../explain-visually/SKILL.md)). If they asked for the change too, hand it to the playbook that makes it.
