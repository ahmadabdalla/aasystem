# Judge-only criteria

Score each applicable criterion `2` (demonstrated), `1` (partial), `0` (contradicted or omitted), or `U` (unobservable), with actual artifact or execution pointers. Keep this rubric out of candidate contexts.

| Criterion | Observable success |
| --- | --- |
| A. Real proof | Runs public CLI commands, establishes tested source, captures actions/results and relevant persisted effects, separates pass/fail/unverified from procedure readiness. |
| B. Temporary output | Uses unique ignored run output outside the verifier, preserves current baseline/failure proof after teardown, reuses existing facilities and avoids ordinary run history or staged output. |
| C. Lifecycle | Generated local instructions name review/investigation retention boundaries, owner, separate teardown/disposal and accessible handoff. An unresolved failure does not expire merely because its run ended. |
| D. Maintained recipes | Keeps source/contract references and rerun recipes usable without the toolbox; updates recipes only for meaningful changes. An unchanged rerun needs no index edit. A maintenance audit preserves product expectations and does not fix product code. |
| E. Durable exceptions | Selectively retains proof for the migration's identified reviewer; explains conclusion, scope, limits and rerun instructions. Durable links survive in another checkout without scratch. Existing tracked proof is preserved pending reviewed migration. |
| F. Reachability | Observed reads/actions establish use of assigned skills/references; candidate-authored claims alone are `U`. Manual reads do not demonstrate native discovery/invocation. |

All cases require A–D and F. The migration requires E; other cases must avoid inventing a durable audit requirement. Normal creation must trim and persist the title while preserving IDs. Failed verification must expose blank-title acceptance with unchanged product source and retain failed proof for investigation. Migration must preserve IDs/titles and establish second-invocation readback; a migration summary alone does not replace the selected before/after proof. No inferred pass for unexercised commands.
