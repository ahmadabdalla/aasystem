# Approved principles

These are the user's preferences between options that both work. Before you settle a decision, check its situation against this table. If a row matches, read that principle and apply it within its scope. If none matches, carry on. If the decision changes, check the table again.

If a principle conflicts with the request, the project's instructions or the evidence, and the conflict changes what you'd do, tell the user. A preference never settles a fact; observe or research it.

If a principle changed a choice, name that choice and any exception in the decision's rationale, and tell the user when it affects your recommendation. Keep both in the record you return.

If you hand work to another agent, pass it the matching principles and their scope: the text, or a path it can open. Give independent candidates the same principles without steering them toward your preferred answer.
